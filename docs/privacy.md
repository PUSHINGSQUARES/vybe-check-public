# Privacy And Optional Services

## Local Core

Sessions, revisions, draft lineage, references, studies, and backups stay under the configured local state root. Source media stays at its registered location. The board binds to loopback and serves registered media through opaque IDs. Its URL grants access to the local session. Keep it private and stop the board with Ctrl+C when finished. Loopback and same-user ownership receipts are boundaries, not protection against a compromised account or other software running as you.

Exports select agreed prompts and settings. They omit full sessions, private media registry paths, and reference bytes. Pattern cleaning removes recognised credential and local-path forms. It cannot identify every name, identity detail, or semantic fingerprint. Inspect exported text before sharing. Don't put secrets in prompts, titles, reference labels, or browser drafts.

The copied ceramic and kite PNG files contain programmatic generic geometry and colour. They are examples, not supplied identity material or model-generated studies. Generated local studies retain generated provenance when promoted. Promotion doesn't establish fidelity.

## Local Studies

Studies are opt-in. Capability inspection uses a configured loopback ComfyUI endpoint and checks its installed nodes and checkpoint. A service running on loopback can still use remote custom nodes: the supported core workflow restricts the allowed graph, and unknown nodes refuse. Don't equate a URL with a guarantee about third-party software.

The supported template uses text conditioning. Registered references aren't silently sent as conditioning. Text-only studies explore framing, light, and colour. They don't preserve exact people or objects, prove reference fidelity, or validate an eventual image or video model. Your own compatible service and checkpoint are prerequisites. Nothing runs at board startup.

## Optional Decision Advice

Core work needs no key. Optional advice sends only the explicitly prepared anonymous question/options contract after outbound inspection and bounded approval. It doesn't send full sessions, reference contents, media, or prompt history. Review every outbound string. Deny tokens and pattern filters reduce exposure but can't guarantee anonymity. A refused, unavailable, weak, or failed response returns to the workshop conversation and never changes agreed prompt bytes, settings, or locks.

Install the optional judge dependencies only when you need advice. Keys are entered through a visible terminal with hidden input and stored in the explicit host-native adapter. Never paste a key into a browser, command argument, environment variable, prompt, or evidence file. macOS Keychain, Linux Secret Service, and Windows Credential Locker access can be denied or unavailable. The runtime refuses rather than choosing a plaintext backend. Installed native-store behaviour remains a real-host verification requirement.

Windows Credential Locker can roam credentials according to Windows account and organisation policy. Check that policy before storing a key; the runtime cannot promise machine-only storage. Linux requires an accessible Secret Service session. Presence status never prints key values.

Advice uses explicit quote and approval documents, a current verified billing bound, and a user-selected ceiling. Missing or stale price authority leaves the route unavailable. No current price, model capability, native-store success, or installed platform support is promised by these documents. No automatic retry, generation provider, or paid image/video submission command exists.

## Preservation

Unregister archives owned registrations and reports unknown or modified files. A filesystem adding unowned metadata can cause refusal before publication; staged bytes remain for review. Don't treat that as proof that native rename failed or waive the unknown-member guard. Updates, rollback, and pip uninstall preserve sessions, media, backups, registration archives, and native keys. See [Lifecycle](lifecycle.md). You decide whether to remove retained private data separately.
